# こども向けミニアプリ集

スマホ・タブレット向けの静的 Web アプリ集です。

## アプリ

- `hiragana.html`: ひらがな学習

- `tsurukame.html`: つるかめ算（つる・かめの頭数と足の数、5問正解でごほうびゲーム一覧へ）

- `fraction.html`: 分数の足し算・引き算
- `fraction-muldiv.html`: 分数の掛け算・割り算

- `kingfisher.html`: カワセミ・ダイブ
- `butterfly.html`: ちょうちょ・フライト

## つるかめ算（tsurukame.html）

- 問題文にはつる＋かめの合計と足の合計を表示し、つると亀の個数を両方入力する。必ず正の整数解になるランダム問題で、同じ問題の重複を避ける。
- つるの足は2本、かめの足は4本。任意のヒント表示、iPadで使える数字パッドと手書きの計算スペースを搭載。
- 間違えても同じ問題に再挑戦し、5問正解するまでごほうびは出ない。5問目の正解で `sessionStorage.miniGameRewardToken` を発行し、共通の `game-menu.html` へ自動遷移。
- 共通ゲーム選択画面でトークンを1回だけ消費し、選んだゲーム1つだけプレイ可能。新ページの開始時に古いトークンを消去する。

## 惑星バトル！（planet-battle/）
- 画面の太陽を指でタッチし、とばしたい方向にスワイプして離すとショット。線と％表示で照準・パワーを確認できる。PCのポインター操作も対応。
- 水星・金星・地球・火星・木星・土星・天王星・海王星の8個を、長方形ビリヤード台の**四隅と上下の中央のブラックホール6個**に入れる。惑星ごとに大きさ・重さ・色・輪・模様が異なる。
- 壁では入射角に応じて物理的に反射（クッション反発係数0.87）。6つのブラックホール以外では落下しない。穴のすぐそばでのみ弱い引力が働く。衝突では質量差・反発係数・摩擦を計算。
- **ショット回数は無制限**。太陽は各ショット後に止まった位置から続けて打てる。太陽がブラックホールに入った場合だけ、空いている中央付近へ再配置。8惑星をすべて入れると勝ち。
- v2では円形の盤面を長方形へ変更し、惑星の初期位置も15ショット以内に攻略可能になるよう調整。
- Canvas 2D描画、固定タイムステップ（1/120秒）でiPadのスワイプでも安定した衝突。衝突効果音はON/OFF可能（Web Audio、端末内生成）。
- 学習の報酬選択画面でトークンを1回消費し、`miniGameAccess:planet-battle`を使って入場。ゲーム直接アクセス・更新・履歴戻りによる再プレイは拒否。終了後は学習メニューへ戻る。
- 静的HTML/CSS/JSのみ。実iPad Safariでのタッチ感度・効果音・機種による描画性能は未確認。

### 惑星バトル v3
- v2の長方形6ポケットビリヤード台、黒いブラックホール、8惑星を維持（v4でショット制限は撤廃）。
- 入力中の青い点線は**実際の物理演算から予測した太陽の軌道**。クッション反射や最初の惑星衝突・ポケットまで表示する。手球が移動中は予測せず、指の移動時だけ計算する。
- ヘッダーに一時停止ボタン。ポーズ画面で再開か学習への終了を選べる。端末からブラウザーが非表示になった場合も自動一時停止し、復帰時の球の時間ジャンプを避ける。
- ブラックホールに到達した球は他球との衝突処理より先に除去することで、吸い込まれた球が他の球を押す現象を防ぐ。
- iPad Safariで狭い表示領域でも画面全体を使えるよう最小高さ制限を撤廃。独立ファイル `trajectory.js` で予測コードを管理。
- `planet-battle/?v=3`、キャッシュバスター更新、共通ごほうびメニューの1回制限はそのまま。

### 惑星バトル v4：iPhone/iPadの画面を広く使い、無制限ビリヤードへ
- 縦画面ではビリヤード台と予測ラインを90度回転し、画面の長辺に合わせて描画。指のタッチ座標も逆回転で正確に変換し、横画面は元の操作方向を維持。台は約1.86:1の一般的なビリヤードらしい比率に調整。
- UIを縮小して中央の盤面を最大限確保。iPhone縦画面ではフッターを畳む。惑星名とパワー表示は縦画面でも読める向きに描画。
- ショット回数の上限なし。8惑星を全て落とすまで何度でも打てる。HUDは「残りの惑星数」「使ったショット数」表示へ変更。
- 太陽は次のショットで**直前に停止した位置を維持**し、ブラックホールへ吸い込まれた時だけ中央付近の衝突しない場所へ復活する。
- ブラックホール半径は53→36に縮小し、降着円盤を紫系からオレンジ・黄色に変更。大きな惑星も角の穴へ入れるよう、クッションの開口を球の大きさに応じて調整。物理的に入れた惑星だけを得点とする。
- レンダラー・物理・軌道予測・ゲーム本体の読み込みを更新し、`planet-battle/?v=4`で配信。学習後に1回だけゲームを選べる仕組みは維持（そのプレイ中のショットは無制限）。
- 端末実機での動作検証は別途必要。JS構文・縦横座標変換・ショット継続・ポケット・壁・勝敗をコード上で検証。

### 惑星バトル v5：小型ブラックホールとパチンコ操作
- 6つのブラックホールの半径を36→18に半減。オレンジ色の降着円盤の描画範囲も半径の約1.27倍へ縮小し、黒い中心部と渦状の光をコンパクトにした。
- 穴の見た目を小さくしても、大きな木星・土星も確実に入れられるよう、ボール外周との接触を考慮した落下判定とクッションの開口角を調整。6穴×小/大惑星の落下検証済。
- 太陽をタッチして**飛ばしたい方向と逆へ引き**、指を離すと引いた方向と正反対へ発射。ゴムの二本線、引っ張った太陽の半透明の目印、前方矢印と物理軌道予測を表示。
- 縦画面で90度回転した盤面も、タッチの逆変換と発射方向を一致させる。横画面でも操作可能。無制限ショット、太陽が停止位置を保持する挙動、ごほうび入場制限はそのまま。
- `planet-battle/?v=5`、`game.js?v=5`、`physics.js?v=6`、`render.js?v=5`、`trajectory.js?v=3`でブラウザーキャッシュを更新。
- JS・模擬Canvas・モックiPadタッチ座標・物理テストは通過。実機iPad Safariでの最終操作確認は別途必要。
