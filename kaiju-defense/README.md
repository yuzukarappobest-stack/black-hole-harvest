# 怪獣防衛線 / KAIJU DEFENSE

学習メニューから独立した、Three.jsの3Dタイムアタック。オリジナルの巨獣ヴォルガを歩兵が倒します。

## 起動

リポジトリのルートで `python3 -m http.server 4183` を実行し、`http://localhost:4183/kaiju-defense/` を開きます。ビルド不要。Three.js 0.164.1をvendorに同梱しています。

## 操作とルール

- スマホ: 左スティックで移動、画面ドラッグで照準。PC: WASDまたは矢印キーで移動、ドラッグで照準。
- 自動連射。照準アシストONでは、ドラッグを離すと怪獣を追尾します。ビルを狙う際はOFFにできます。
- ビルは銃弾6発、または怪獣の攻撃で崩れます。赤い円は怪獣の攻撃範囲です。
- 攻撃を受けても体力は減らず、1.5秒の転倒から復帰します。
- 怪獣を倒した時点でタイムが確定。自己ベストをlocalStorageに保存します。
- 一時停止中・別タブ表示中は時間が止まります。単独試作版のため再出撃可能です。

## 構成

- main.js: ゲーム進行、射撃、怪獣の攻撃、カメラ、記録
- actors.js: 歩兵と怪獣の低ポリゴンモデル
- world.js: 街区、ビルの崩壊、再利用する破片と弾道
- input.js: タッチ・キーボード
- audio.js: Web Audioの射撃音・怪獣音
- config.js: 体力、連射速度、移動速度、転倒時間

建物の破壊は軽量な縮退アニメーションと破片による表現です。破片の物理シミュレーションや建物の内部、複数怪獣、学習アプリとの連携はこの版には含めていません。

## 検証

ChromeとWebKitの自動ブラウザテストで起動・自動射撃・撃破・自己ベスト保存・再出撃を確認。Chromeでは2本指による移動と照準の同時操作、銃撃によるビル崩壊、転倒と復帰、一時停止も確認しました。

390x844 / 1024x768 / 1440x900 / 844x390の描画と操作UIを検査。照準アシストONの静止テストでは約59秒で撃破。iPhone/iPad実機での検証は未実施です。
