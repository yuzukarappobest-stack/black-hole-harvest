# 怪獣防衛線 / KAIJU DEFENSE

学習をクリアした後に一度遊べる、Three.jsの3Dタイムアタック。オリジナルの巨獣ヴォルガを歩兵が倒します。

## 起動

リポジトリのルートで `python3 -m http.server 4183` を実行し、`http://localhost:4183/learn.html` から学習をクリアしてゲームを選びます。ビルド不要。Three.js 0.164.1をvendorに同梱しています。ゲームURLへの直接アクセスや使用済みページの復元は学習メニューへ戻ります。

## 操作とルール

- スマホ: 左スティックで移動、画面ドラッグで照準。PC: WASDまたは矢印キーで移動、ドラッグで照準。
- 自動連射。右ドラッグで右、左ドラッグで左に照準が動きます。指を離すとその向きを保ちます。自動追尾はありません。
- ビルは銃弾6発、または怪獣の攻撃で崩れます。赤い円は怪獣の攻撃範囲です。
- 攻撃を受けても体力は減らず、1.5秒の転倒から復帰します。
- 怪獣を倒した時点でタイムが確定。自己ベストをlocalStorageに保存します。
- 一時停止中・別タブ表示中は時間が止まります。終了後は「がくしゅうへ」リンクで学習メニューへ戻ります。再出撃には再度学習が必要です。

## 構成

- main.js: ゲーム進行、射撃、怪獣の攻撃、カメラ、記録
- actors.js: 歩兵と怪獣の低ポリゴンモデル
- world.js: 街区、ビルの崩壊、再利用する破片と弾道
- input.js: タッチ・キーボード
- audio.js: Web Audioの射撃音・怪獣音
- config.js: 体力、連射速度、移動速度、転倒時間
- access.js: 一回限りのプレイ権と履歴からの復元対策

建物の破壊は軽量な縮退アニメーションと破片による表現です。破片の物理シミュレーションや建物の内部、複数怪獣はこの版には含めていません。

## 検証

ChromeとWebKitの自動ブラウザテストで起動・自動射撃・撃破・自己ベスト保存・再出撃を確認。Chromeでは2本指による移動と照準の同時操作、銃撃によるビル崩壊、転倒と復帰、一時停止も確認しました。

学習連携版ではリトライを廃止。全15学習メニューの登録を検査し、WebKitでたしざん・おんぷ・しょう5文章題からの入場、クリア後の学習メニューへのリンク、直接アクセス・再読み込み・履歴復元の拒否を確認しました。

390x844 / 1024x768 / 1440x900 / 844x390の描画と操作UIを検査。初版の照準アシストONの静止テストでは約59秒で撃破（現在は手動照準のみ）。iPhone/iPad実機での検証は未実施です。
