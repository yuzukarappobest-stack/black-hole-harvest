# カートレース 3D

学習アプリの「ごほうびゲーム」から選べる、Three.js 製の独立した周回レースです。

- ループ状のサーキットを 3 周
- 自車 1 台 + CPU 5 台。CPU は走行ライン・コーナー減速・追い越しを制御
- 自動アクセル、左右への傾きハンドル、押している間だけブレーキ
- iOS Safari の DeviceOrientation 許可（スタートタップで要求）およびハンドルの再中心化
- 傾きが使えない場合：路面画面を左右ドラッグ。PC：左右キー/A・D、Space でブレーキ
- 走行速度・順位・ラップ・タイム・ミニマップ・ベストタイム
- コースアウトすると速度が落ち、大きく外れると自動復帰＆時間ペナルティ
- CPU が先にゴールしても自車が3周終えるまでプレイ継続
- 既存の \`miniGameAccess:kart-race\` を消費する1回限りのごほうびゲーム。終了後は学習メニューへ戻る

## 実装

- \`index.html\` / \`style.css\`：スマホUI
- \`track.js\`：閉じた Catmull-Rom サーキット、路面、縁石、景色、距離・コース投影
- \`controls.js\`：傾き入力・再キャリブレーション・ドラッグの代替・ブレーキ
- \`game.js\`：3D レンダリング、カート、CPU、物理・順位・周回、HUD

Three.js 0.164.1 を CDN から ES module で読みます。静的サイトとして配信できます。

## 重要な確認項目
1. 学習完了後、ごほうびゲームで「カートレース 3D」を選べる。直接URLを開いても遊べない。
2. iPhoneでSTARTを押し、傾きの許可を与えた後、傾きに応じて旋回する。横向きと縦向きを試す。
3. ブレーキを押している間だけ減速し、小回りできる。ドラッグ/矢印キーも試す。
4. CPU5台が周回し、追い抜くと順位が入れ替わる。ミニマップの印も進む。
5. 1周、2周、3周でラップ表示が進み、3周のフィニッシュ後に結果画面が出る。
6. 背景から戻った際に一時停止できる。結果画面から「がくしゅうへ もどる」で戻れる。
7. iPhoneの実機で FPS・メモリ・操作方向・路外判定を確認する。

## 留意点
Playwright/実機での操作感の最終確認がまだ必要です。既存の「レース」は従来のまま残しています。
