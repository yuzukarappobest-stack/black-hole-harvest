# SPIN CLASH / コマバトル3D

独立して遊べる、オリジナルの1対1コマバトル。学習メニューとの連携はありません。

## 起動

リポジトリのルートで `python3 -m http.server 4184` を実行し、`http://localhost:4184/spin-clash/` を開きます。ビルド・npm install不要。

## 操作

- 左スティック、またはスタジアム上のドラッグで移動。PCはWASD・矢印キー。
- 右のダッシュボタン、またはスペースキーで加速。方向入力がない時は相手の方向へダッシュします。
- ストーム（バランス）、ブレイズ（攻撃）、バルク（防御）から選択。
- 最大45秒の対戦。相手が場外へ出るか回転力が0になると勝利。時間切れは残り回転力で判定。同時場外・同時停止は引き分け。
- 一時停止・アプリ非表示中は時計と物理演算を停止。最速勝利をコマ別に端末へ保存。

## 構成

- main.js: 対戦進行・相手AI・勝敗・表示
- physics.js: cannon-esによる平面上の剛体衝突。見た目の回転・揺れはvisuals/main側。
- visuals.js: 立体コマ・スタジアム・火花。図柄はCanvasで生成。
- input.js / audio.js: 操作・合成効果音
- config.js: 対戦時間、ダッシュ間隔、コマの重さ・速度・攻撃力・防御力
- vendor: Three.js 0.164.1 / cannon-es 0.20.0。ネットワークCDNなしで配信可能。

実物のコマの回転運動・摩擦は厳密な再現ではなく、遊びやすさを優先したモデルです。コマのデザイン・名称はオリジナルです。

## 検証

WebKitで3タイプの対戦完了、勝利・敗北・同時場外の引き分け・回転停止・時間切れ、一時停止、再戦を検証。操作するテストでは約14〜22秒で勝利、無操作では約20〜27秒で敗北しました。

Chromeでは2本指の移動とダッシュの同時操作、およびダッシュの衝突による場外勝利を確認。390x844、1024x768、1440x900、844x390のスクリーンショット・描画ピクセル・操作UIの画面内配置も検査しました。iPhone/iPadの実機検証は未実施です。
